# ابدأ من هنا — تشغيل مساعدك الشخصي (بدون برمجة)

هذا الدليل لك إذا ما تعرف برمجة. كل خطوة فيها «وش تسوي» و«وش تشوف». الوقت التقريبي: ٤٥ دقيقة. Claude Code يسوي الجزء التقني معك خطوة خطوة؛ دورك تضغط وتنسخ وتلصق.

## 1. وش تحتاج قبل ما تبدأ

- [ ] جوال عليه **تيليجرام**.
- [ ] كمبيوتر (ويندوز أو ماك) تفتح عليه الطرفية.
- [ ] حساب **GitHub** (مجاني): https://github.com/signup
- [ ] حساب **Railway** (الاستضافة): https://railway.com — الخطة المجانية التجريبية تكفي للتجربة، والاستمرار يحتاج بطاقة دفع.
- [ ] اشتراك **Claude** (Pro أو Max) أو حساب API — لازم للتعديلات التلقائية.
- [ ] مفتاح **Gemini** مجاني: https://aistudio.google.com/apikey
- [ ] ٤٥ دقيقة فاضية.

> ما تحتاج تولّد الأسرار بنفسك. Claude يولّدها ويقول لك وين تلصقها.

## 2. ثبّت Claude Code وأضف مهارة البناء

1. **ثبّت Claude Code** (تطبيق سطح المكتب أو الأمر في الطرفية) من الصفحة الرسمية: https://claude.com/claude-code — واتبع خطوات نظامك.
2. **أنشئ مجلداً فاضياً** باسم مساعدك في أي مكان تبيه (مثلاً `مساعدي` على سطح المكتب).
3. **افتح الطرفية داخل المجلد:** على ويندوز كليك يمين داخل المجلد ← **Open in Terminal**؛ على ماك كليك يمين على المجلد ← **New Terminal at Folder**. اكتب كلمة واحدة: `claude` ثم Enter، وسجّل دخولك لو طلب. (لو استخدمت تطبيق سطح المكتب، افتح المجلد من داخله.)
4. **أضف المهارة:** اكتب هذين السطرين (واحد واحد):

```
/plugin marketplace add Nfarahat99/assistant-builder
/plugin install assistant-builder@assistant-builder
```

**وش تشوف:** Claude يقول إن المهارة انثبتت (لو طلب إعادة تحميل اكتب `/reload-plugins`).

## 3. ابنِ مساعدك

اكتب:

```
/assistant-builder:build-assistant
```

أو قل بكلامك: «ابنِ لي مساعدي». المهارة تمشّي معك خطوة خطوة، وتسوي الجزء التقني بنفسها.

Claude يسألك أول: **الأسئلة الشخصية** (شغلك، أولوياتك، أسلوبك) تجاوبها هنا الحين، أو لاحقاً مع المساعد في تيليجرام — اختر اللي يريحك. بعدها أسئلة قصيرة (اسمك، اسم المساعد، أيام دوامك…) ثم:

- يكتب ملف `assistant.config.json` بإجاباتك.
- يولّد لك الأسرار: `TELEGRAM_LINK_CODE` و`DASHBOARD_PASSWORD` و`SECRETS_KEY` و`WEBHOOK_SECRET` (لواتساب لاحقاً)، ويحطها في ملف `.env` على جهازك (ما يُرفع لـ GitHub أبداً).
- يمشّيك في إنشاء الحسابات: بوت تيليجرام من @BotFather، مفتاح Gemini، توكن Claude (`claude setup-token`)، توكنات GitHub، مشروع Railway. أي توكن تلصقه في ملف `.env` أو في صفحة الأسرار — **مو في المحادثة**.
- يتأكد إن توكن تيليجرام ومفتاح Gemini **صحيحين** (`npm run doctor -- --online`) — لو انلصق واحد غلط يقول لك فوراً.
- يتحقق **مين صاحب المستودع**. لو المستودع باسم شخص ثاني وأنت مضاف عليه فقط، يشرح لك وش اللي لازم صاحبه يسويه (أو ينقل المستودع لحسابك)، ويجهّز لك رسالة جاهزة ترسلها له.

**لو عندك ريبو مساعد من قبل:** افتح Claude داخله وقل: «اقرأ onboarding/interview.md ونفّذه». (لو قال لك Claude «افتحني داخل مجلد المستودع»: سكّر الطرفية، وافتحها من جديد **داخل مجلد المستودع**، واكتب `claude`، ثم قل له: «كمّل onboarding/interview.md».)

**الأوامر اللي تكتبها بنفسك:** `claude setup-token` و — لو احتجنا — `gh auth login`، كل واحد في نافذة طرفية ثانية لأنه يفتح المتصفح باسمك. المهارة تقول لك متى. الباقي كله هي تسويه.

**خذ نسخة من `TELEGRAM_LINK_CODE` و`DASHBOARD_PASSWORD` (من ملف `.env`) في مكان آمن** (`DASHBOARD_PASSWORD` للوحة في الخطوة ٥، و`TELEGRAM_LINK_CODE` احتياط للخطوة ٤).

### الإعداد على Railway (واجهة الموقع — الأسهل)

Claude يوجّهك لها، وهذا ملخصها لو احتجت ترجع:

1. https://railway.com ← **New Project** ← **Deploy from GitHub repo** ← اختر مستودع مساعدك. (لو ما ظهر: **Configure GitHub App** واسمح بالمستودع. لو المستودع باسم شخص ثاني، صاحبه هو اللي يسمح.)
2. **قاعدة البيانات:** داخل المشروع اضغط **+ New** (أو `Ctrl/⌘ + K`) ← **Database** ← **PostgreSQL**.
3. اربط القاعدة بخدمة المساعد: افتح خدمة المساعد ← **Variables** ← **New Variable**: الاسم `DATABASE_URL` والقيمة `${{Postgres.DATABASE_URL}}` (لو سمّيت خدمة القاعدة غير Postgres، بدّل الاسم).
4. **التخزين (Volume):** اضغط `Ctrl/⌘ + K` (أو كليك يمين على لوحة المشروع) ← أنشئ **Volume** ← اختر خدمة المساعد ← **Mount path** = `/data`. ثم أضف متغير `FILES_DIR` بقيمة `/data/files`.
5. **المتغيرات:** في **Variables** ← **Raw Editor** ألصق سطور ملف `.env` اللي فيها قيم — الأسرار اللي ولّدها Claude والمفاتيح اللي لصقتها (مثل `GEMINI_API_KEY` و`TELEGRAM_BOT_TOKEN` و`TELEGRAM_LINK_CODE` و`DASHBOARD_PASSWORD` و`SECRETS_KEY`).
6. **الرابط العام:** خدمة المساعد ← **Settings** ← **Networking** ← **Public Networking** ← **Generate Domain**.
7. **أسرار GitHub:** في صفحة مستودعك ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**: أضف `CLAUDE_CODE_OAUTH_TOKEN` (من `claude setup-token`) و`TEMPLATE_SYNC_TOKEN` (انظر `docs/TEMPLATE.md` القسم ٤).
   - **لو المستودع مو باسمك** (أنت مشارك فقط): ممكن ما تقدر تضيف الأسرار ولا تربط Railway. الأسهل: صاحب المستودع ينقله لحسابك (Settings ← General ← Transfer ownership)، أو يضيف السرّين ويسمح لـ Railway بنفسه — Claude يجهّز لك رسالة له بدون أي أسرار. وتوكن GitHub هنا يكون من النوع **Classic** (Claude يمشّيك فيه).

> أول نشر يفشل غالباً قبل ما تضيف المتغيرات، وهذا طبيعي. بعد ما تلصق المتغيرات يعيد Railway النشر (أو اضغط **Redeploy**).

**وش تشوف:** بعد دقيقتين أو ثلاث يصير النشر أخضر (Deployed). افتح `https://رابطك/health` وتشوف رد قصير فيه `"ok":true`.

### بديل بالأوامر (لو تفضّل الطرفية)

الواجهة أفضل للأسرار. أوامر الطرفية تحفظ المفاتيح اللي تكتبها في سجل الطرفية (shell history)، فتجنّب كتابة الأسرار فيها لو جهازك مشترك.

بعد `railway login` وربط المشروع بـ `railway link`:

```bash
railway add --database postgres
railway volume add --mount-path /data
railway variables set FILES_DIR=/data/files GEMINI_API_KEY=... TELEGRAM_BOT_TOKEN=...
railway up
railway domain
```

(وما زلت تحتاج إضافة `DATABASE_URL` كمرجع للقاعدة من الواجهة كما في الخطوة ٣ من إعداد Railway.)

### فحص الجاهزية

قبل النشر (أو أي وقت) اطلب من Claude: «شغّل npm run doctor». (Claude ثبّت Node والاعتماديات في الخطوة ٢، فيشتغل مباشرة.) الأمر نفسه:

```bash
npm run doctor
```

يطبع سطور ✅ (تمام) و⚠️ (تنبيه) و❌ (لازم تصلحه). لا تنشر وفيه ❌.

## 4. اربط تيليجرام وابدأ المقابلة الشخصية

بعد ما يصير النشر أخضر:

1. قل لـ Claude: «افتح رابط ربط تيليجرام» (يشغّل `npm run telegram-link`). ينفتح لك رابط بوتك في المتصفح — **بدون ما تنسخ أي رمز**.
2. اضغط **Start** (أو «ابدأ»). لو سألك المتصفح، اختر فتح تيليجرام. يشتغل من تيليجرام الكمبيوتر أو الويب، وبعدها تكلم البوت من جوالك عادي (نفس الحساب).
3. **لو ما انفتح الرابط:** افتح بوتك في تيليجرام واكتب `/start` ثم مسافة ثم قيمة `TELEGRAM_LINK_CODE`.

**وش تشوف:** البوت يرحّب فيك ويبدأ **المقابلة الشخصية** تلقائياً: ٨ أسئلة قصيرة تجاوب عليها بصوت أو بنص. (لو جاوبت الأسئلة الشخصية مع Claude في الخطوة ٣، البوت يرحّب بس — هو يعرفك من قبل.)

أوامر المقابلة:

- «تخطّ» — يتجاوز السؤال الحالي.
- «وقف المقابلة» — يوقفها.
- «كمّل المقابلة» — يرجع يكمّلها من وين وقفت.

بعدها جرّب: `مساعدة` ثم `ذكرني بعد دقيقتين أختبر`.

## 5. لوحة التحكم

- **الرابط:** رابط Railway العام + `/dashboard` — مثال: `https://اسم-مشروعك.up.railway.app/dashboard`
- **كلمة المرور:** قيمة `DASHBOARD_PASSWORD`.

أهم الأقسام:

- **الإعدادات** — تعديل بياناتك، وفيها زر **إعادة المقابلة** لو تبي تعيد المقابلة الشخصية من الأول.
- **النماذج** — تختار نموذج الذكاء لكل دور (فهم، عام، صوت…). الافتراضي Gemini.
- **الحسابات** — ربط واتساب (انظر الخطوة ٦).

## 6. واتساب (لاحقاً)

واتساب **اختياري** ويشتغل بعد ما يجهز الوسيط. تيليجرام يكفي ويبقى الاحتياط دائماً.

1. افتح اللوحة ← **الحسابات** (في الجوال: **المزيد** ← الحسابات).
2. لو الصفحة تقول «غير متاح»، فهي تعرض لك بالضبط وش الناقص. عادةً: `GATEWAY_URL` و `GATEWAY_PROVISION_KEY` (من صاحب الوسيط)، و `WEBHOOK_SECRET` (كلمة سر 16 حرفاً أو أكثر — يولّدها Claude لك). ضعها في Railway ← Variables، وانتظر إعادة النشر، وارجع للصفحة. (أسهل: قل لـ Claude «اقرأ onboarding/interview.md وجهّز إعدادات ربط واتساب» — يقول لك وش تطلب من صاحب الوسيط ووش جاهز عندك.)
3. اكتب **رقم المساعد** (رقم مخصص على جوال ثاني) و**رقمك**، وعلّم «فاهم الخطر»، واضغط **ابدأ الربط**.
4. على جوال المساعد: واتساب ← الإعدادات ← **الأجهزة المرتبطة** ← ربط جهاز، وامسح الرمز. الرمز يتجدد كل ٢٠ ثانية تقريباً.
5. لما يتم الربط توصلك رسالة ترحيب على واتساب، والمساعد يعيد تشغيل نفسه خلال ثوانٍ وترجع الصفحة.

لو مسحت الرمز بجوال غلط، أو انتهت مهلة الرمز، الصفحة تقول لك — اضغط **رمز جديد** وجرّب. وتقدر تفك الربط من نفس الصفحة بزر **فك الربط**.

> **تحذير الحظر:** الوسيط غير رسمي، وأرقام واتساب ممكن تنحظر. استخدم **رقماً مخصصاً للمساعد** وليس رقمك الأساسي. افتراضياً، المساعد ما يرسل لأحد غيرك إلا بموافقتك على النص (يعطيك رابط wa.me ترسله بنفسك). اللوحة تعرض هذا التحذير، وتيليجرام يبقى احتياطاً.

## 7. لو صار شي

**أول خطوة دايماً:** شغّل `npm run doctor` (أو اطلب من Claude: «شغّل npm run doctor واشرح لي النتيجة»).

| الرسالة أو المشكلة | المعنى | الحل |
|---|---|---|
| ❌ assistant.config.json لسا على القيم التجريبية — شغّل المقابلة التقنية (onboarding/interview.md) في Claude Code (ونفس الرسالة لو رفض الإقلاع) | ملف الإعدادات ما زال على قيم المثال | قل لـ Claude: «اقرأ onboarding/interview.md ونفّذه» |
| ❌ ملف assistant.config.json غير موجود / مو JSON صالح | الملف ناقص أو انكسر | قل لـ Claude: «اقرأ onboarding/interview.md ونفّذه» |

| ❌ SECRETS_KEY ناقص أو غير صالح — لازم 64 خانة hex … (أو ⚠️ SECRETS_KEY غير صالح) | المفتاح ناقص أو بصيغة خاطئة | اطلب من Claude: «ولّد SECRETS_KEY جديد»، والصقه في Railway ← Variables |

| ⚠️ ما فيه GEMINI_API_KEY — المساعد ما بيفهم الرسائل … | ما فيه مفتاح ذكاء | خذ مفتاح من https://aistudio.google.com/apikey والصقه في Railway ← Variables |
| ⚠️ ما فيه DASHBOARD_PASSWORD — لوحة التحكم معطّلة لين تضيفه | اللوحة ما تفتح | اطلب من Claude يولّده، والصقه في Railway ← Variables |
| ⚠️ ما فيه PUBLIC_URL ولا RAILWAY_PUBLIC_DOMAIN … (long polling) | ما فيه رابط عام | طبيعي على جهازك. على Railway: **Settings ← Networking ← Generate Domain** |

**مين تكلم:** الصق لـ Claude Code نص الخطأ ونتيجة `npm run doctor` وقل «وش المشكلة؟». لو ما انحلت، تواصل مع من زوّدك بالقالب وأرسل له نتيجة `npm run doctor` (بدون أي أسرار).

> **تنبيه أمان:** لا تشارك قيم `TELEGRAM_BOT_TOKEN` أو `SECRETS_KEY` أو `DASHBOARD_PASSWORD` مع أي شخص، ولا تلصقها في صور أو منشورات.
